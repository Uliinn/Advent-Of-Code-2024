# Advent of Code 2024

My solutions for [Advent of Code 2024](https://adventofcode.com/2024), written in Python.

## Structure

Each day has its own folder (`1/` through `25/`) containing:
- `1.py` — solution for part 1
- `2.py` — solution for part 2
- `input.txt` — puzzle input

## Setup

To scaffold the folder structure for all 25 days:

```bash
python createSetup.py
```

This creates folders `1/` through `25/`, each with empty `1.py`, `2.py`, and `input.txt` files.

## Running a solution

```bash
cd <day>
python 1.py
python 2.py
```
